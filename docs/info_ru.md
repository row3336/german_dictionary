German Dictionary Bot

Описание
Бот для ведения немецкого словаря и прохождения квизов. Поддерживает:
- Ручной и AI‑импорт слов
- Долгосрочное расписание SM2
- Session‑retry для закрепления внутри сессии
- Weak‑моды по формам (лечения и закрепление)
- Синонимы
- Статистику и дампы

Доступ
Бот owner‑only. Все действия доступны только владельцу.

Языки словаря
Поддерживаются пары:
- Немецкий → Русский
- Немецкий → Украинский
- Немецкий → Английский

Меню
Главное меню:
- Add words
- Quiz
- Settings
- Statistics

Quiz:
- L1 > De (L1 = выбранный язык словаря: RU/UK/EN)
- De > L1

L1 > De:
- Standart mode SM2
- Article Weak Mode
- Plural Weak Mode
- Verb Forms Weak Mode
  - Prateritum Weak Mode
  - Partizip2 Weak Mode

Добавление слов
1) Precheck (коррекция + тип)
- Список предварительно распознаётся AI.
- Показ списка в формате `word [type]`.
- Кнопки: Approve, Edit list, Reject list.
- Edit list: отправляете исправленный список, он сразу идёт в распознавание без повторного precheck.

2) Распознавание (AI)
- Каждый элемент проходит полное распознавание полей.
- Формат предпросмотра:
  - Nomen: der Großvater (Großväter) - дедушка
  - Verb: bleiben (blieb / geblieben) - оставаться

3) Подтверждение
- Confirm сохраняет слово.
- Clarify AI / Clarify field — правки.
- Reject / Ban — отказ.

Квизы
L1 > De (SM2):
- Для существительных: article + german + plural.
- Для глаголов: правильный ответ = infinitiv + partizip2.
  - prateritum не влияет на правильность.
  - Допустимо: `infinitiv partizip2` или `infinitiv prateritum partizip2`.

De > L1 (SM2):
- Перевод на L1, проверка по нормализованным вариантам.

SM2 (долгосрочно)
SM2 — алгоритм интервальных повторений.
- Правильные ответы увеличивают интервал повторения.
- Ошибка сбрасывает интервал на 1 день.
- В выдаче только due‑слова (`due <= today`).

Session‑retry (краткосрочно)
- Очередь повторов внутри сессии.
- После ошибки слово добавляется в retry‑очередь.
- После каждых 3 обычных вопросов показывается одно retry‑слово.
- Retry не влияет на SM2.
- На слово даётся 4 повтора.
- Очередь очищается при выходе из Quiz.

Weak‑моды (формы)
Active weak:
- {form}_errors >= 2 или {form}_streak_wrong >= 2.

Review weak:
- После выхода из active запускается закрепление:
  - stage 1: +1 день
  - stage 2: +2 дня
  - stage 3: +5 дней
  - затем завершение
- Ошибка в review → сброс на stage 1.

Синонимы
- Добавление/удаление/очистка групп
- Автосвязь по переводу
- Только одинаковые типы

Статистика
- Общее количество слов
- Количество по типам
- Слова, на которые не отвечали
- Weekly прирост
- Стрики
- Weak‑количества
- Точность

Хранилище
SQLite: `data/words.db` (DB_PATH).
