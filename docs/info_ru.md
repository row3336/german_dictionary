Бот построен на алгоритме периодичности повторений SuperMemo2.

Краткая логика работы:
1-й правильный ответ: следующее повторение через 2 дня
2-й правильный подряд: через 6 дней
3-й правильный подряд: примерно через 15 дней (может чуть плавать из-за коэффициента)
Неверный ответ - сброс интервала на 1 день

Полная логика:
В классической версии каждое слово оценивается пользователем по шкале от 0 до 5
5 - Perfect response / Правильный, без колебаний.
4 - Correct response after hesitation / Правильно, но с паузой.
3 - Correct response recalled with serious difficulty / Правильно, но с большим трудом.
2 - Incorrect response; correct one seemed easy to recall / Ответ неверный, но после показа кажется "знал".
1 - Incorrect response; correct one remembered / Неверно, почти не помнил.
0 - Complete blackout / Полностью не вспомнил

В случае бота эта шкала упрощена в данный момент до двух оценок для автоматизации процесса:
Correct -> quality = 5
Wrong -> quality = 2

Для каждой пары пользователь + слово + режим квиза хранится:
interval (дней до следующего показа)
repetitions (сколько успешных повторений подряд)
ease (коэффициент легкости, старт 2.5)
due (дата следующего показа)

Старт:
Новое слово: interval=1, repetitions=0, ease=2.5, due=today.

Оценка ответа:
Внутренняя оценка:
Correct -> quality = 5
Wrong -> quality = 2

То есть ручная шкала 0..5 не используется, только автооценка по факту ответа.

Обновление после ответа:
1.
Если quality < 3 (ошибка):
repetitions = 0
interval = 1

2.
Если quality >= 3 (правильно):
если repetitions == 0 -> interval = 2 дня
если repetitions == 1 -> interval = 6
иначе -> interval = round(interval * ease)
затем repetitions += 1

3.
Обновление легкости:
ease = ease + (0.1 - (5-quality)*(0.08 + (5-quality)*0.02))
минимальное ограничение: ease >= 1.3

4.
Новая дата:
due = today + interval

Прогресс независим:
между пользователями
между режимами (RU->DE, DE->RU, Article)

То есть одно и то же слово в разных режимах имеет разные интервалы и даты показа.
