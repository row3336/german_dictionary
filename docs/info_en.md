Bot commands:
/start - launch (sometimes you need to send it again if the bot does not respond)

Menu:
1) Add Word - you can send one word to add, a list of words (one per line) in one message, or a text file with words, and they will be added to the bot
2) Tests - this is where testing happens, three test modes are available
3) Settings - choose interface language and dictionary language
4) Statistics - currently this shows the number of words in the bot dictionary

How it works (SuperMemo2 algorithm):
1st correct answer: next repetition in 2 days
2nd correct in a row: in 6 days
3rd correct in a row: about 15 days (may vary slightly due to the ease factor)
Wrong answer - interval is reset to 1 day
