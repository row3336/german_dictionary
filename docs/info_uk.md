German Dictionary Bot

Опис
Бот для ведення німецького словника та проходження квізів. Підтримує:
- Ручний та AI‑імпорт слів
- Довгострокове планування SM2
- Session‑retry для закріплення всередині сесії
- Weak‑режими за формами (лікування і закріплення)
- Синоніми
- Статистику та дампи

Доступ
Бот owner‑only. Усі дії доступні лише власнику.

Меню
Головне меню:
- Add words
- Quiz
- Settings
- Statistics
- Info

Quiz:
- L1 > De
- De > L1

L1 > De:
- Standart mode SM2
- Article Weak Mode
- Plural Weak Mode
- Verb Forms Weak Mode
  - Prateritum Weak Mode
  - Partizip2 Weak Mode

Додавання слів
1) Precheck (корекція + тип)
- Список попередньо розпізнається AI.
- Показ списку у форматі `word [type]`.
- Кнопки: Approve, Edit list, Reject list.
- Edit list: надсилаєте виправлений список, він одразу йде в розпізнавання без повторного precheck.

2) Розпізнавання (AI)
- Кожен елемент проходить повне розпізнавання полів.
- Формат попереднього перегляду:
  - Nomen: der Großvater (Großväter) - дідусь
  - Verb: bleiben (blieb / geblieben) - залишатися

3) Підтвердження
- Confirm зберігає слово.
- Clarify AI / Clarify field — правки.
- Reject / Ban — відмова.

Квізи
L1 > De (SM2):
- Для іменників: article + german + plural.
- Для дієслів: правильна відповідь = infinitiv + partizip2.
  - prateritum не впливає на правильність.
  - Дозволено: `infinitiv partizip2` або `infinitiv prateritum partizip2`.

De > L1 (SM2):
- Переклад на L1, перевірка за нормалізованими варіантами.

Article Quiz (SM2):
- Перевірка артикля для іменників.

SM2 (довгостроково)
- У due потрапляють лише `due <= today`.
- Помилка → interval=1, due=завтра.
- У той самий день SM2 повторів немає.

Session‑retry (короткостроково)
- Черга повторів всередині сесії.
- Після помилки слово додається у retry‑чергу.
- Після кожних 3 звичайних питань показується одне retry‑слово.
- Retry не впливає на SM2.
- На слово дається 4 повтори, навіть якщо відповіді правильні.
- Черга очищується при виході з Quiz.

Weak‑режими (форми)
Active weak:
- {form}_errors >= 2 або {form}_streak_wrong >= 2.

Review weak:
- Після виходу з active запускається закріплення:
  - stage 1: +1 день
  - stage 2: +2 дні
  - stage 3: +5 днів
  - далі завершення
- Помилка у review → скидання на stage 1.

Синоніми
- Додавання/видалення/очистка груп
- Автозв’язок за перекладом
- Лише однакові типи

Статистика
- Загальна кількість слів
- Кількість за типами
- Слова, на які не відповідали
- Weekly приріст
- Стрики
- Weak‑кількості
- Точність
